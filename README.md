# Fragenkatalog – INNOTECH

Online-Fragenkatalog für Auftraggeber und weitere Stakeholder. Statische Seite (fertig gebaut, alles in `index.html`),
Daten in Supabase (Projekt „Protokoll“). Aufruf nur mit persönlichem Zugangslink: `…/fragenkatalog/?z=<Code>`.
Quellcode und Datenbankmigrationen: separates Paket `fragenkatalog_quellcode.zip`.
